1. The 4-State Tool Lifecycle State Machine

Following Anthropic and AI SDK guidelines, the four tool states answer four distinct user questions with unique visual treatments:

State 1 · input-streaming

Input Streaming

Question: "What is the AI doing?"

Pulsating cyan telemetry card rendering live JSON argument tokens typing out in real time.

State 2 · input-available

Input Available

Question: "With what parameters?"

Indigo execution card confirming parsed parameters with active server radar spinner.

State 3 · output-available

Output Available

Question: "What came back?"

Morphs smoothly (200ms crossfade) into the TriageScoreCard featuring the hand-rolled SVG risk radar chart.

State 4 · output-error

Output Error

Question: "What went wrong?"

Designed recovery card with error code (ERR_TRIAGE_TIMEOUT) and working "Retry Tool" button.

2. Server-Side Tool Contracts & Zod Schemas

Primary Tool: assessCrisisRisk

export const TriageAssessmentSchema = z.object({
  patientQuery: z.string().describe('The distress query shared by the user'),
  severityLevel: z.enum(['mild', 'moderate', 'severe', 'acute']).describe('Primary psychiatric risk tier'),
  symptoms: z.array(z.string()).describe('Extracted distress symptoms (insomnia, panic, hopelessness)'),
  affectiveTension: z.number({ min: 0, max: 100 }).describe('Emotional tension index (0-100)'),
  cognitiveOverload: z.number({ min: 0, max: 100 }).describe('Mental fatigue & racing thoughts (0-100)'),
  somaticInsomnia: z.number({ min: 0, max: 100 }).describe('Physical distress & sleep disruption (0-100)'),
  immediateHarmRisk: z.boolean().describe('Immediate self-harm ideation or intent detected')
});
